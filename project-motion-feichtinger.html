From Print Mascot to Interactive Web Element

The illustrated locator character was originally created for print and branding materials of Ortungstechnik Feichtinger. To bring technical leak detection to life on the web, the segmented vector layers from Adobe Illustrator were rigged and animated in Adobe After Effects.

Four distinct interaction states were choreographed: searching with a magnifying glass, giving a confident thumbs-up confirmation with a wink, a walk cycle, and a micro-motion rising directly from the main CTA button.

Performance via Bodymovin & Lottie JSON

Rather than using heavy GIF files or video clips, all animations were exported via the Bodymovin extension as lightweight vector JSON files.

This approach guarantees sub-second loading performance, sharp rendering on high-DPI Retina screens, and precise programmatic control to trigger playback on scroll or hover events.

Client / Context Feichtinger & Academic
Software Illustrator, After Effects
Web Tech Bodymovin / Lottie JSON
Discipline Character Design & Motion

The Character Pipeline

To give technical leak detection a friendly, approachable face, an illustrated locator character was created in Adobe Illustrator with segmented body rigs. In Adobe After Effects, 4 key choreographies were keyframed: searching with a magnifying glass, giving a confident thumbs-up with a wink, a looping walk cycle, and an interactive micro-motion lifting up from a CTA button.

Performance via Bodymovin / Lottie

Instead of heavy video files or GIFs, animations were exported via Bodymovin as lightweight, vector-based Lottie JSON files. This ensures crystal-sharp rendering on Retina displays, instant loading times, and full programmatic control (triggering on hover, scroll, or click).
